# ITS Network Security Reviewer

A static reviewer and questionnaire app for ITS-style network security exam practice.

## Features

- High-yield reviewer cards for core network security topics
- Focused likely-exam question bank aligned to the ITS Network Security objective domains
- Randomized 50-item questionnaire per take
- Immediate feedback and explanations after every answer
- Final score plus missed-item review
- Searchable and filterable full question bank
- Dark mode with saved preference
- Searchable text-based reviewer PDF export through the browser print/save dialog
- Extra downloadable glossary for important terms that appear as answer choices

## Run

Open `index.html` in a browser.

No build step or package installation is required.
